Básicamente una papa hashbrown gigante, pero le faltaba *mucha* sal. Tal vez así es como se supone que se come, pero para mí el sabor estaba súper plano. La porción completa quizá era demasiada; debí haberla pedido como guarnición para que no se sintiera cara para ser solo papa con aceite de oliva.
